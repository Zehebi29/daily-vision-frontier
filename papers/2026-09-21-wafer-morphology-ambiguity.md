# 🏭 晶圆质检不该硬挂一个科——给 AI 一张「哪些缺陷容易看走眼」的分诊表

> **Paper**: Morphology-Aware Ambiguity Learning for Wafer Defect Decision Support
> **arXiv**: `2609.21866`
> **Published**: 2026-09-18 | **Authors**: Seungjun Chu, Seokhyun Chung（高丽大学 工业与管理工程系）
> **Links**: [arXiv](https://arxiv.org/abs/2609.21866) | [PDF](https://arxiv.org/pdf/2609.21866)

## 📝 一句话总结

**这篇论文相当于给晶圆质检 AI 设了一个医院分诊台：有把握的直接挂专科，正好卡在两个科室边界的就开「联合门诊」报两个候选，实在说不清才送人工全检。最关键的是——那张「哪两个科室最容易互相看走眼」的对照表，不是统计模型犯错次数得来的，而是从缺陷本身的形状里算出来的。**

---

## 🧐 这论文在干什么？（用大白话）

### 这解决的是什么问题？

设想一张晶圆图（wafer map）：圆圆的硅片上画满小格子，每格是一颗芯片，只有三种状态——片外、良品、坏品。把坏品涂黑，就会浮现出某种**形状**：正中一团（Center / Donut）、贴着边缘的一段弧或整圈（Edge-Loc / Edge-Ring）、片内一团或几乎全坏（Loc / Near-full）、散碎点（Random）、一条斜穿的细线（Scratch），以及什么都没坏（Nonpattern）。

这就像给病人拍 X 光片：**病灶形状 = 病名**，九个类 = 九个科室，看图分类 = 分诊。

麻烦在于：有些片子**天生就站在两个科室中间**。WM-811K 数据集的作者自己（Wu et al., 2015）就承认，标成 Center 的图有些完全可以算 Donut 或 Loc，而 Loc 又常和别的类打架。过去所有方法都被要求「必须挂一个科」——那这种图被判错，到底是 AI 菜，还是片子本来就模糊？论文说：**这两种情况必须分开处理。**

### 以前的方法为什么不行？

- **硬标签交叉熵**：正确答案满分，其余全 0 分。等于判卷只认标准答案，沾边的解法一律 0 分——把「这题本来就模糊」这条信息直接抹掉。
- **标签平滑（LS）**：给所有错类平均撒一点分。等于说「除了正确答案，别的都可能」——听着谦虚，其实什么都没说。
- **选择性分类 / 拒识**：没把握就转人工。分诊台只有两档——直接挂科 or 送会诊，「这两个科都看一下」根本不存在。
- **保形预测**：返回候选集合，但集合里可能是 { 划痕, 无花样 } 这种废话组合：要么有病灶要么没病灶，医生看了想打人。

## 💡 核心思想（第一性原理）

### 核心洞察

**模型的混淆矩阵告诉我们「模型常把谁认成谁」，那是模型的毛病，不该写进教科书。** 论文要的是「缺陷的形状告诉我们谁和谁真的像」，于是完全绕开神经网络，只用公式化的形状描述子算类间相似度，得到一张**与模型无关**的对照表 A。

### 方法拆解

**1️⃣ 给每张晶圆图写一份 23 项「形状体检报告」**

- **径向 10 维**：把圆盘切成 10 个同心环，数每环坏点密度 → 病灶在中心、中环还是边缘？
- **角度 6 维**：外圈切 12 个扇形，用傅里叶变换去掉「从哪个角度开始数」的影响，再除掉总量 → 只看绕圈分布均不均匀（晶圆是圆的，转一下不该改变诊断）。
- **7 个标量**：平均半径、空心度（Donut 中心是空的）、环状度（整圈 vs 一段弧）、覆盖率（Near-full）、离心率（细长条 = Scratch）、连通度（碎点 = Random，成团 = Loc）、直线度（霍夫变换量划痕）。

> 这三栏就是分诊问诊表：**哪儿疼、范围多大、疼成什么形状**。

**2️⃣ 由报告统计出「哪两个科室容易看走眼」→ 模糊矩阵 A**

给每个缺陷类拟合一个对角协方差高斯混合模型（GMM）——即「本科室的典型症状画像」；用混合而非单个高斯，是因为同一缺陷出现在不同位置朝向上长相本来就分好几种。对每对类 (j, k) 算**方向性对数似然比**：拿 k 科的画像去解释 j 科的病人，顺不顺？这个量**不对称**——「拿 Donut 标准解释 Center」和反过来难度不同。转成相似度 `s = exp(-d/τ)`（τ 自动取所有非对角 d 的中位数，不用手调），再组装成矩阵：每行一个类，**对角留 δ=0.8 给自己**，剩下 0.2 按相似度分给别的缺陷类。**Nonpattern 单独硬处理**：它的行是 one-hot——「没有花样」不是一种形态，跟「有花样」之间不存在长得像这回事。整张表**只算一次**（CPU 不到 5 分钟），所有模型、所有种子共用。

**3️⃣ 训练时不给错类判 0 分，而是按表给「沾边」的类一点分**

损失 = (1−λ)·硬标签交叉熵 + λ·软目标交叉熵（λ=0.6），软目标 = 0.8·真类 + 0.2·(A 的第 y 行)。

> 就像判卷：正确答案给 80 分，剩下 20 分**按「哪种解法跟标准解法最接近」分配**，而不是平均撒给所有解法。注意这是**类级**软标签，不需要逐实例的多标注。

**4️⃣ 推理时三色分诊**

最高概率 ≥ 0.95 → 报 1 个类（🟢 直接挂专科）；概率不够但 top-2 这一对在 A 里够像、且两个都不是 Nonpattern → 报 2 个候选（🟡 联合门诊）；其余 → 人工全检（🔴 专家会诊）。

置信门槛故意卡到 0.95，因为半导体厂对晶圆图分类器部署前的期待是近 99% 准确率——判错会把错误的失效机理喂进根因分析。而「送全检」那一档里 **58.7% 其实是 Nonpattern**：真正难的不是区分两种缺陷，而是判断「到底有没有缺陷」。

### 🎭 贯穿全文的类比

> 整个方法就是在**建一个分诊台**：
> - 23 维形状描述子 = 分诊问诊表（哪儿疼 / 范围 / 形状）
> - GMM 类条件分布 = 每个科室的「典型症状画像」
> - 模糊矩阵 A = 贴在墙上的《易混淆科室对照表》，**由症状统计而来，不是医生吵架记录**
> - 软标签损失 = 判卷给沾边解法部分分
> - 0.95 / τ_A 两道门槛 = 两档放行标准；自动 / 联合 / 全检 = 绿 / 黄 / 红三色分诊

## 🔬 实验怎么说？

| 他们想验证什么？ | 怎么验证的？ | 结果怎么样？ |
|----------------|------------|------------|
| 加表会不会把普通分类精度搞坏？ | WM-811K，ResNet-34，4 个种子，70/10/20 划分 | 九类 macro-F1 从 0.9154 → **0.9201**；只看八个缺陷类 0.9176 → **0.9245**。约 9.4 万张测试图，原来错 8.4%，现在错 7.6% |
| 提升来自「有这张表」，还是来自「表是从真实形状算的」？ | 两个对照：A_unif（所有缺陷类平均撒 0.2）、A_PCA（同流程但用原始像素造表） | A_unif 0.9120、A_PCA 0.9138，都远不如 A_morph 0.9245 → **光软化标签没用，光用数据算关系也不够，必须贴合缺陷定义的形态特征** |
| 三色分诊真的分得开吗？ | 统计每组覆盖率与命中率 | 🟢 覆盖 94.2%，其中 99.75% 直接命中；🟡 仅 1.9%，但 top-2 命中 95.2%；🔴 3.8% |
| 黄灯给的两个候选比「光看概率」给的有用吗？ | 与置信度路由对比（同样三路、同样 0.95 门槛） | 置信度路由黄灯更大（4.8%），但只有 **24.8%** 的对子是「两个真缺陷类」，其余是 {Scratch, Nonpattern} 这类废话；本方法 **100%** 都是两个真缺陷类 |

两点补充：相对成本模型下每片期望成本从 0.0810 降到 0.0656（**约省 19%**）；换七种骨干（含非卷积的 Swin-Tiny），绿灯命中率稳定在 99.72%~99.80%——说明机制几乎不依赖架构。

### 消融实验说明了什么？

- **拆掉 δ（对角给自己留多少分）**：0.5 太软（连真类都学糊了，还不如平均撒分的对照）、0.9~1.0 太硬（等于没加表）、0.8 最好。而且 δ 和 λ 必须**联合调**：λ=0.3 时最优 δ 并不是 0.8。就像调味——盐和糖得一起尝，单独调一样必然调错。
- **拆掉「相似度各不相同」**（换成 A_unif）：所有类对相似度一样，调 τ_A 时只能一起过或一起不过，黄灯组会在某个阈值上**断崖式消失**；而 A_morph 的相似度有高有低，τ_A 可以**平滑地**调节黄灯规模，去匹配当天的复核人力。另外，因为 Nonpattern 行被压硬，任何含它的对子相似度恒为 0，天然被挡在黄灯之外。

## ⚠️ 哪里还不够好？

1. **对照表是「科室级」而不是「病人级」的**：同一对类里有的图确实模糊、有的其实很清楚，但 A 只给一个分。就像墙上写着「心内科和呼吸科容易混」，可具体到这个病人可能一点都不难分。
2. **第二候选是否真的合理，从没被验证过**：数据集每片晶圆只有**一个**专家标注，论文无法证明第二个候选是工程师也认可的替代诊断。这就像考试只有唯一标准答案，却让学生交「答案 A 或 B」——没人能证明 B 真能得分。
3. **成本模型是自设的相对系数，不是真实产线的账**：19% 的节省只在假设的价目表下成立。
4. **只能在固定九类里玩**：混型缺陷、从未见过的新花样都不覆盖。硬把新花样塞进九类中的某一类，分诊台会自信地挂错科。

    └── CNN / 旋转不变网络 / 自监督表征 (2018–2022) ← 花样看得越清越好，但仍必须挂一个科

## 🌍 如果这个能实际用上…

1. **晶圆厂良率分析**：全检人力按「是否需要」分配，而不是「模型没把握就全送人工」。
2. **任何类边界天然模糊的分类任务**：PCB AOI（露铜 vs 划伤）、医学影像分级（BI-RADS 4a/4b）、钢材表面等级——只要有人愿意定义「什么算像」。
3. **作为可移植套路**：只要手头有确定性的领域特征（几何、时序、频谱），就能造出**与模型无关**的模糊矩阵，给任何分类器外挂一条「可解释的第二意见」通道，且不用重训模型。

## 🎯 一句话记住

> **模型犯错 ≠ 数据模糊。区分这两者，靠的不是模型的概率，而是缺陷自己的形状。**
> 先用形状统计出「谁和谁真的像」，再让 AI 在没把握时只报这两个候选、说不清才叫人工——质检 AI 就从「必须给答案」变成了「懂分诊」。
